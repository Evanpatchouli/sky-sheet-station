# Code Review Records

Store focused review reports here when a task needs a durable review artifact.

Suggested filename: YYYY-MM-DD-short-change-name.md.

Each review should include:
- reviewed commit or diff reference;
- scope and files inspected;
- findings ordered by severity, with file and line references;
- tests or checks inspected;
- limitations and unverified areas.

Do not create an empty review report for routine changes. A review record is useful only when it preserves findings or important verification evidence.
