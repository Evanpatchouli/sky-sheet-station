# Task Context

Store only durable, task-specific context that is not already captured in AGENTS.md, GOALS.md, PLANS.md, or docs/.

Suggested filename: YYYY-MM-DD-short-task-name.md.

Each context note should state:
- the task it supports;
- source files and decisions relied upon;
- assumptions and unresolved questions;
- when the note becomes stale.

Do not copy the entire repository documentation into context notes. Link to the source of truth instead.
